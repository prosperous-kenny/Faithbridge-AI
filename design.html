Design Preview

FaithBridge AI

Proposed visual system for the web application: color ramps, type scale, button variants, and form controls. Every value below is a proposal — nothing here is wired into the app yet.

The ramps deliberately match Tailwind's default indigo, amber, and slate scales, so adopting them costs nothing beyond extending the theme in apps/web/tailwind.config.ts, which is currently empty. Indigo carries institutional trust, amber carries warmth and generosity. Click any swatch to copy its hex.

02

Typography

Two families, both loaded from Google Fonts. Inter carries all interface and body text — it is drawn for small sizes and holds up on low-density displays. Source Serif 4 is reserved for display, h1, and h2, giving the brand a warmer, more editorial voice without putting a serif in dense UI. Everything below h3 stays sans so labels and data remain quick to scan. Both are loaded with display=swap and fall back to the system stack, so the page still renders correctly offline.

03

Buttons

One primary action per view. Minimum height 42px so the hit target clears the 44px accessibility guidance at the medium size. Hover and focus states below are live — tab into them.

Variants

VariantUse for
primaryThe single main action of a view
secondarySupporting actions beside the primary
accentDonor-facing and giving flows
ghostTertiary actions in toolbars and cards
dangerDestructive, irreversible actions

Sizes

Large for marketing and empty states, medium for forms and dialogs, small for dense tables. Small sits below the 44px target, so keep it out of primary flows.

States

Loading preserves the button's width so the layout does not shift. Disabled controls keep their label rather than blanking out.

05

Porting to Tailwind

To adopt this system, move the custom properties into the empty theme.extend block in apps/web/tailwind.config.ts and replace the three lines of app/globals.css with a Tailwind v4 @theme block. The two webfonts would move to next/font, which self-hosts them at build time and removes the Google Fonts request entirely. Until then this file is documentation, not a dependency.
